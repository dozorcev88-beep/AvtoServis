# АвтоСервис Android — прототип v1

Это первая кликабельная версия интерфейса, адаптированная под Android.

## Что работает
- Главная панель со сводными показателями
- Создание клиентов
- Создание заказов и изменение статусов
- Простой склад запчастей
- Учёт расходов и обзор финансов
- Список сотрудников и ролей (пока демонстрационный)
- Сохранение данных в браузере устройства через localStorage

## Как открыть на Android
1. Разместите содержимое папки на HTTPS-хостинге (например, собственном веб-сервере).
2. Откройте адрес в Chrome на Android.
3. В меню Chrome выберите «Установить приложение» или «Добавить на главный экран».

Локально можно открыть index.html в браузере, но установка PWA и service worker требуют HTTPS (или localhost).

## Важные ограничения v1
Это прототип для проверки экранов и сценариев. Данные пока хранятся только в браузере одного устройства.
Одновременная работа нескольких сотрудников, настоящие учётные записи, серверная база, защищённые роли,
резервное копирование и синхронизация ещё не подключены. Не используйте прототип как единственную базу реального сервиса.
