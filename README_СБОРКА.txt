АвтоСервис Android — проект для сборки APK

Важно:
Это Android-проект-оболочка для текущего прототипа. В нём работает интерфейс и локальное сохранение на одном телефоне.
Облачная база, синхронизация между сотрудниками и настоящие серверные роли ещё не реализованы.

Как собрать APK:
1. Установите Android Studio на компьютер.
2. Распакуйте архив.
3. В Android Studio выберите Open и укажите папку AvtoServisAndroid.
4. Дождитесь Gradle Sync. При первом запуске Android Studio скачает Android Gradle Plugin и SDK (нужен интернет).
5. В меню Build выберите Build Bundle(s) / APK(s) → Build APK(s).
6. После сборки нажмите locate в уведомлении Android Studio. APK обычно будет в:
   app/build/outputs/apk/debug/app-debug.apk
7. Перенесите APK на телефон и установите. При необходимости разрешите установку приложений из этого источника.

Для публикации и реального использования нужна подписанная release-сборка, серверная БД, авторизация сотрудников и серверная проверка прав доступа.

Сборка через GitHub Actions с телефона:
1. Создайте на github.com бесплатный аккаунт или войдите.
2. Создайте новый репозиторий (например, AvtoServisAndroid).
3. Загрузите ВСЕ файлы и папки проекта, включая скрытую папку .github/workflows.
4. Откройте вкладку Actions. Запустится workflow Build Android APK.
5. Откройте завершившийся запуск, внизу страницы Artifacts скачайте AvtoServis-debug-apk.
6. Распакуйте artifact ZIP — внутри будет app-debug.apk.
Если Actions не запустился автоматически, откройте Actions → Build Android APK → Run workflow.
